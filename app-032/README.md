# 花灯骨架放样与蒙面裁片 · Lantern Frame Lofting

纯前端工具：选灯型 → 填直径/高度/收口 → 出「每根竹篾截多长、弯什么角度」的骨架件表、带缝份的蒙面裁片、以及可 100% 打印的 1:1 放样图与备料单。无后端、无网络请求，断网可用。

## 技术栈

- Vue 3（`<script setup>` 单文件组件）+ TypeScript + Vite 6
- 状态：Vue 自带 `ref / reactive / computed / watch`（无 Pinia / Vuex）
- 额外依赖仅 `vue-router` 4（规格书要求的 6 个路由）
- 手写 CSS；无 UI 组件库、无图表库、无游戏引擎/物理库
- 字体、灯型数据包（`src/data/lantern-types.json`）全部本地打包，无外网 CDN

## 两处打印取舍（已按「尺寸正确优先」选定，后果自担）

1. **骨架长条跨页**：相邻两段**真实多搭一截**（默认搭接 10mm，可改）——拼的时候标尺读数连续、对位十字能接上；代价是同一根长条多占纸、段数多一段。段编号按构件一顺接下去（`FM###-i/n`），跨页不断号、不重号。改搭接量后段数、每段起点、编号整体重算（CHK-10 断言）。
2. **裁片放不下可打印区**：**整块挪到单独一页居中、仍 1:1**——拓印尺寸永远正确；代价是费一张纸。绝不就地切半、绝不缩小。A4 放不下时 CHK-12 明确提示换 A3；CHK-06 只在真正出现「同一裁片被拆成两页」时失败。

## 编号总核对（图纸页 / 标签页 / 构件清单同一份结论）

- 裁片编号 `P###`：裁片清单、1:1 图纸（每种 1 块 1:1 样）、裁片标签三处一一对得上，不重不漏。
- 长条编号 `FM###-i/n`：与构件清单编号同号（CSV 也带此列），段内顺序连接。
- 裁片标签：**每 10 张一页，多出来的自动续页**，逐块编号 `P###-01…P###-qty` 全列出，一张不漏。
- 改纸张幅面或搭接量后，图纸宽高 / 可打印区 / 分页 / 长条分段 / 对账单全部跟着刷新（CHK-09）。

## 1:1 打印要点

- `@page { size: <幅面毫米>; margin: 0 }` 由代码按所选 **A4(210×297) / A3(297×420)** 动态注入——换纸张后不再沿用 A4 纸宽（修复「选 A3 打出 A4 宽、右边整条缺失」）。
- 内容四周留 8mm 安全边，落在打印机非打印区内，避免浏览器触发「适应页面」自动缩放。
- 100mm 校验尺 / 垂直尺 / Ø100 校验圆均按标称 100mm 绘制（CHK-11）；打印后若量得 96mm 一类，说明打印对话框仍在「适应页面 / Fit」或纸张选错。
